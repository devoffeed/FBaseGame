Динамичный 10-минутный арена-шутер от первого лица на движке Unity с проработанной локацией и тактическими ИИ-ботами. Проект создан для быстрых и насыщенных игровых сессий.

## Особенности игры

* **Быстрые матчи (10 минут).** Короткий и интенсивный формат сессий без затянутого вступления.
* **Проработанная карта.** Сбалансированная арена с укрытиями, перепадами высот и тактическими точками.
* **Умные ИИ-боты.** Противники ориентируются в пространстве, используют укрытия, ведут огонь и реагируют на действия игрока.
* **Качественная графика.** В проекте используются PBR-текстуры, HDRI-освещение и 3D-модели высокого разрешения.

## Управление

* **W, A, S, D** — передвижение
* **ЛКМ** — стрельба
* **ПКМ** — прицеливание
* **Пробел** — прыжок
* **Shift** — ускорение (спринт)
* **R** — перезарядка

## Запуск проекта в Unity

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте **Unity Hub**, нажмите **Add** и выберите корневую папку скачанного проекта.
3. Запустите проект (рекомендуется версия Unity **6.3** или новее) и откройте основную сцену в папке `Assets/Scenes`.
4. Чтобы просто поиграть без установки движка, скачайте готовую сборку в разделе [Releases](https://github.com).
